## Relações importantes
- `WAServerProperties` → `WAContext/WAContextMain` (high): WAServerProperties exposes userContext/setUserContext/configureUserContext and isInternalUser; WAContextMain exists only in main executable.
- `WAContext` → `WAContextMain` (high): SharedModules has WAContext/container classes; main executable has WAContextMain concrete graph with many managers/services.
- `WAABProperties` → `FOAWAABPropertiesImpl` (high): FOAWAABPropertiesImpl exposes boolForKey/stringForKey/integer accessors and wraps AB properties.
- `WAAuraGating` → `WAAura/WAAuraFoundation controllers` (high): SharedModules exposes AuraGating/GatedBenefit/GatedSubscription; main executable exposes AppThemesViewController/AppIconsViewController/AuraProviding.
- `FOA` → `WAFoaAppUtilities` (high): WAFoaAppUtilities exposes installed-state class properties for Facebook/Instagram/Threads/MetaAI.
- `WABiz` → `WAABProperties` (high): WABiz.BizManager contains an abProperties ivar; many WABiz surfaces are server/AB gated.
- `Contacts/About` → `WAInfoTopHeaderView.OnlinePresenceDotView` (medium): OnlinePresenceDotView is UI only; actual gates are likely WAAB/WAContextMain services.

## Import/Export
O backup JSON exporta preferências/overrides do WATweaks, não o estado bruto dos binários. Na importação, o JSON é tratado como fonte da verdade: chaves WATweaks ausentes no JSON são removidas do NSUserDefaults.
